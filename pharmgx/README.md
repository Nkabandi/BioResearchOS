# pharmgx — Pharmacogenomics Reporter

Flagship project. Turns a genetic dataset (WGS, genotyping array, or plain-text genotypes) into a gene–drug interaction report aligned to CPIC/PharmGKB conventions.

## Input

`sample_input/demo_patient.txt` — demo genotypes for a virtual patient. Format: `gene,rsid,genotype`.

## Output

`sample_output/` — generated by `python clawbio.py run pharmgx --demo`:

| File | What |
|------|------|
| `report.md` | Human-readable clinical summary (phenotype + drug dosing guidance) |
| `report.html` | Same report, HTML |
| `result.json` | Structured findings (machine-readable) |
| `reproducibility/commands.sh` | Exact command used to regenerate |

## Run it

```bash
# demo (no network, no setup)
python clawbio.py run pharmgx --demo --output out/

# your own data
python clawbio.py run pharmgx --input genotypes.txt --output out/
```

## Example report excerpt

```
Gene Summary
  CYP2D6     Poor metabolizer
  CYP2C19    Normal metabolizer
  ...

Drug Summary
  ■   1 Avoid / use alternative
  ■  24 Use with caution
  ■  17 Standard dosing
  ■  17 Insufficient data

Full report → out/report.md
```

## Methodology

Gene–drug rules live in the skill's `SKILL.md` (CPIC/PharmGKB aligned). No invented thresholds: every value traces to the documented tables. The disclaimer is mandatory in every report.
