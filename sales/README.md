# Lead Tracking (CRM)

One row per contact. Update after every interaction. KPI column is **Status** —
the pipeline is: `contacted → replied → call → trial → client → testimonial`.

| Column | What to record |
|--------|----------------|
| Name | Person's name |
| Institution | University / lab / company |
| Need | What they said they need (quote it if possible) |
| Date_Contacted | First outreach date (YYYY-MM-DD) |
| Follow_up | Date of next follow-up (3-5 days after contact) |
| Status | contacted / replied / call / trial / client / testimonial |

## Working the list

1. Add 20-30 leads/week (Master's students, PhD students, research groups, small biotech startups, academic labs).
2. One service per message — the **AI-assisted literature review** (search, compare, organize references, structured report).
3. After 3 days with no reply, one follow-up. After that, move on.
4. If someone asks for something else (figures, data analysis), log it in Need — that's market feedback that drives the roadmap.

## Weekly KPI (not GitHub stars)

| Metric | Target |
|--------|--------|
| Outreach sent | 20-30/week |
| Replies | ≥ 10% reply rate |
| Discovery calls | ≥ 2/week |
| Trial projects | 1/month |
| Paying clients | first within 60 days |

## Student-priced offer (starting point)

- **Literature review (basic)**: ~2-4 pages, 8-12 references, structured summary — affordable flat price.
- **Data summary**: descriptive stats + charts + plain-language notes.
- **Presentation cleanup**: slide deck review / figure polish.

Raise prices once you have testimonials.
